# Vocabulary Review Changelog

## 2026-04-25

- Opened the `vocabulary-review` requirement stream.
- Captured the product direction that vocabulary review should focus on contextual learning, special-expression awareness, active recall, and a lightweight review queue.
- Scoped the first review mode to cloze recall from the original sentence.
- Defined the first learning-state model: `new`, `due`, and `mastered`, driven by `Forgot`, `Unsure`, and `Know` feedback.
